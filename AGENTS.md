# Repository Agent Instructions

- Make every change on a dedicated branch and deliver it through a pull request. Never commit new work directly to `main`.
- Always use squash merge.
- Never include private or internal repository information in commit messages, pull requests, or related artifacts. Notify the user promptly if a requested change would require it.
- Prefer the smallest implementation. The best code is code that does not need to be written.
- Explain concepts in plain language with small, direct examples or analogies when useful.
