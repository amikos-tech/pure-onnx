<threat_model>
## Assets

- Session and tensor native handles
- Caller-owned input/output memory
- Session serialization and global lock ordering
- Inspectable error and diagnostic channels

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller-supplied `[]Value` → native Run | Counts, implementation provenance, handle validity, and lifetimes must be validated before pointer arrays cross FFI. |
| Concurrent Run/Destroy → native handles | Session and tensor handles must remain live for the complete native call without deadlock. |
| Native status → public error | Status-owned details must become Go-owned once and must not also be logged. |

## STRIDE Threat Register

Threat identifiers, categories, severities, and dispositions are canonical in `02-VALIDATION.md` § Canonical Threat Register; this table scopes those definitions to Plan 02-04.

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering / Elevation of Privilege | HIGH | RunWithValues input/output arrays | mitigate | Accept sealed package-created Values only and validate counts/nil/destroyed/unsupported state before FFI. |
| T-02-02 | Denial of Service | HIGH | shared run core and handle leases | mitigate | Preserve runMu→ortCallMu→mu→Tensor.runMu order, deduplicated leases, reverse release, deterministic race tests, and KeepAlive barriers. |
| T-02-03 | Tampering / Denial of Service | HIGH | three session status paths | mitigate | Route every status through the release-owning converter and assert ORTError fields/release accounting. |
| T-02-11 | Denial of Service | HIGH | session finalizer handler | mitigate | Use the tested finalizer-safe diagnostic wrapper; normal returned paths never invoke it. |
| T-02-08 | Repudiation / Denial of Service | MEDIUM | returned session failures | mitigate | Recording-handler tests require zero diagnostic records for every returned path. |
| T-02-SC | Tampering | LOW | package-manager inputs | mitigate | Add no dependency and leave module files unchanged. |
