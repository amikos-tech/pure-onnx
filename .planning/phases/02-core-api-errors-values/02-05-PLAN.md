<threat_model>
## Assets

- Pinned Go tensor backing arrays
- Native OrtValue and OrtMemoryInfo handles
- Tensor run lease and explicit Destroy semantics
- Error and diagnostic channels

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Shape/data supplied by caller → native tensor creation | Dimensions, element counts, data length, and byte size must be validated before raw pointers cross FFI. |
| Run/Destroy concurrency → native OrtValue | A handle and pinned backing must remain live until every active read lease ends. |
| Native creation status → Go error | Status-owned message/code must be copied and released exactly once. |

## STRIDE Threat Register

Threat identifiers, categories, severities, and dispositions are canonical in `02-VALIDATION.md` § Canonical Threat Register; this table scopes those definitions to Plan 02-05.

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering / Elevation of Privilege | HIGH | parsed and programmatic tensor shape/data validation | mitigate | Wrap ParseShape, ShapeElementCount, and tensor validation with ErrInvalidArgument, preserve strconv causes, and reject before native pointer use. |
| T-02-02 | Denial of Service | HIGH | pinner, runMu, Destroy | mitigate | Preserve lock order, read leases, KeepAlive, exact unpin/release behavior, and deterministic race tests. |
| T-02-03 | Tampering / Denial of Service | HIGH | tensor native statuses | mitigate | Use the one release-owning converter and assert copied fields/exact release. |
| T-02-11 | Denial of Service | HIGH | tensor finalizer handler | mitigate | Use finalizer-safe structured emission; explicit errors return normally without logging. |
| T-02-08 | Repudiation / Denial of Service | MEDIUM | tensor returned errors | mitigate | Recording-handler tests require zero events for every returned error path. |
| T-02-SC | Tampering | LOW | package-manager inputs | mitigate | Add no dependency and leave module files unchanged. |
