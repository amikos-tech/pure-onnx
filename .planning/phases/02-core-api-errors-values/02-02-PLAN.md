<threat_model>
## Assets

- Native tensor handles and their private lease protocol
- Caller-owned tensor data and explicit destruction semantics
- Public `Value` compatibility surface

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| External Go package → `ort.Value` | A caller can pass interface values into native session execution, but must not be able to supply forged native handles. |
| Generic `Value` → typed tensor access | A caller requests an exact `Tensor[T]` view without changing element representation or ownership. |

## STRIDE Threat Register

Threat identifiers, categories, severities, and dispositions are canonical in `02-VALIDATION.md` § Canonical Threat Register; this table scopes those definitions to Plan 02-02.

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering / Elevation of Privilege | HIGH | `Value`, `AsTensor`, session value inputs | mitigate | Seal `Value` with an unexported marker, retain raw handles/leases privately, and permit only package-created implementations. |
| T-02-02 | Denial of Service | HIGH | typed-nil and mismatched values | mitigate | Reject typed nil in exact extraction and leave native-run validation to the established lease path; add nil/mismatch tests. |
| T-02-09 | Denial of Service | MEDIUM | generic public API | mitigate | Use baseline-compatible direct type assertions and compile every existing consumer package. |
| T-02-SC | Tampering | LOW | package-manager inputs | mitigate | Add no dependency and require `go.mod`/`go.sum` to remain unchanged. |
