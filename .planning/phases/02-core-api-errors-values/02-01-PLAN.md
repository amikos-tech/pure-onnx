<threat_model>
## Assets

- Native `OrtStatus` lifetime and its status-owned message memory
- Caller-visible error categories and native error details
- Process-global ORT function-pointer state

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ONNX Runtime native ABI → Go | A nonzero native status and status-owned message cross the purego `uintptr` boundary into Go-owned error data. |
| Package internals → public caller | Local sentinels and `ORTError` fields become compatibility contracts consumed through `errors.Is`/`errors.As`. |

## STRIDE Threat Register

Threat identifiers, categories, severities, and dispositions are canonical in `02-VALIDATION.md` § Canonical Threat Register; this table scopes those definitions to Plan 02-01.

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-02-03 | Tampering / Denial of Service | HIGH | `statusToError`, GetErrorCode/GetErrorMessage/ReleaseStatus | mitigate | One helper installs release before access, copies all status-owned data, and proves exact one-release behavior under race plus a separate real ABI test. |
| T-02-04 | Repudiation | MEDIUM | public error chain | mitigate | Separate local sentinels (`errors.Is`) from native `ORTError` (`errors.As`) and retain operation/code/message fields. |
| T-02-09 | Denial of Service | MEDIUM | Go API baseline | mitigate | Use Go 1.25-compatible `errors.As`; do not use Go 1.26-only `errors.AsType`. |
| T-02-SC | Tampering | LOW | package-manager inputs | mitigate | Install no package and require `go.mod`/`go.sum` to remain unchanged. |
