<threat_model>
## Assets

- Downloaded ONNX Runtime artifacts, checksums, and cache contents
- Filesystem/archive path containment and safe permissions
- Network/filesystem error causes used for remediation
- Diagnostic records that may include paths or URLs

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Network/cache/archive input → local runtime artifact | Untrusted metadata, bytes, archive names, and redirects are validated by existing bootstrap controls. |
| OS/network/filesystem failure → public error | Lower causes must remain traversable without leaking into an unrelated category. |
| Bootstrap notice → consumer handler | Only selected non-returnable context may be emitted; URLs must be redacted. |

## STRIDE Threat Register

Threat identifiers, categories, severities, and dispositions are canonical in `02-VALIDATION.md` § Canonical Threat Register; this table scopes those definitions to Plan 02-07.

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-02-04 | Repudiation | MEDIUM | bootstrap error chains | mitigate | Preserve `%w`/errors.Join and assert lower/cleanup causes with Is/As. |
| T-02-07 | Information Disclosure | HIGH | bootstrap diagnostic attrs | mitigate | Redact URLs, allowlist attrs, exclude tokens/headers/environment values, and test recorded output. |
| T-02-08 | Repudiation / Denial of Service | MEDIUM | returned bootstrap failures | mitigate | Emit only twelve enumerated non-returnable notices and assert zero records for returned errors. |
| T-02-10 | Tampering / Elevation of Privilege | HIGH | artifact download/cache/archive handling | mitigate | Preserve HTTPS, checksum, path-containment, size, and lock tests; add anchored `TestBootstrapCreatedFilePermissions` coverage for Unix-safe bootstrap directories, installed TGZ/ZIP libraries, and lock files with a Windows POSIX-mode skip. |
| T-02-SC | Tampering | LOW | package-manager inputs | mitigate | Use standard errors/slog only; leave module files unchanged. |
