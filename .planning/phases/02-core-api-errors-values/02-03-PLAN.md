<threat_model>
## Assets

- Process-wide diagnostic configuration
- Potentially sensitive path, URL, and error context emitted by later call sites
- Availability of finalizer and concurrent runtime paths

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Consumer code → `slog.Handler` | An arbitrary consumer-supplied handler is installed into process-wide package state and may be called concurrently. |
| `ort` internal event → consumer output | Structured attributes leave the package only at explicitly audited, non-returnable diagnostic sites. |

## STRIDE Threat Register

Threat identifiers, categories, severities, and dispositions are canonical in `02-VALIDATION.md` § Canonical Threat Register; this table scopes those definitions to Plan 02-03.

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-02-06 | Denial of Service | MEDIUM | consumer handler panic during general diagnostic emission | accept | `SetDiagnosticHandler` explicitly installs consumer-owned synchronous code as a trusted callback; document and test normal slog panic propagation rather than silently swallowing the consumer bug. |
| T-02-07 | Information Disclosure | HIGH | diagnostic attrs | mitigate | Keep emission private and standard-attribute-based; Plans 04-07 allowlist/redact concrete attrs and add call-site tests. |
| T-02-08 | Repudiation / Denial of Service | MEDIUM | returned-error reporting | mitigate | Provide no automatic returned-error hook and require concrete zero-emission audits in downstream plans. |
| T-02-11 | Denial of Service | HIGH | handler reconfiguration and finalizer emission | mitigate | Atomically swap immutable logger state, test concurrent emit/configure under race, and recover consumer-handler panics at the library-owned finalizer boundary. |
| T-02-SC | Tampering | LOW | logging dependencies | mitigate | Use `log/slog`, `sync/atomic`, and existing standard library only; leave module files unchanged. |
