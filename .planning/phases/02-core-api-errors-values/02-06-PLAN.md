<threat_model>
## Assets

- Process-global ORT library, environment handle, function pointers, and refcount
- Underlying OS/library/symbol and cleanup causes
- MemoryInfo native handle ownership
- Runtime-version and cleanup diagnostics

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Filesystem/dynamic loader → environment API | External OS/library failures enter the public error chain and must remain reachable. |
| Native CreateEnv/CreateMemoryInfo → Go | Status-owned error data must be copied/released exactly once. |
| Concurrent environment/resource teardown → function pointers | The existing lifecycle locks must prevent stale native calls. |
| Version/finalizer notice → consumer handler | Only non-returnable, non-sensitive structured context may leave the package. |

## STRIDE Threat Register

Threat identifiers, categories, severities, and dispositions are canonical in `02-VALIDATION.md` § Canonical Threat Register; this table scopes those definitions to Plan 02-06.

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-02-02 | Denial of Service | HIGH | environment/refcount/memory teardown locks | mitigate | Acquire CreateMemoryInfo's ortCallMu read lock before mu and retain it through status conversion; prove the exclusive teardown lock cannot enter, and preserve existing race/refcount tests. |
| T-02-03 | Tampering / Denial of Service | HIGH | CreateEnv/CreateMemoryInfo status paths | mitigate | Use the sole status converter and assert exact release plus ORTError fields. |
| T-02-04 | Repudiation | MEDIUM | OS/library/cleanup error chains | mitigate | Preserve `%w` and `errors.Join`; test underlying causes with Is/As. |
| T-02-06 | Denial of Service | MEDIUM | consumer handler panic at the runtime-version diagnostic | accept | Treat the explicitly installed consumer handler as trusted synchronous code and document/test normal slog panic propagation. |
| T-02-07 | Information Disclosure | HIGH | runtime-version diagnostics | mitigate | Emit only runtime/API version attrs; never attach environment values or credentials. |
| T-02-08 | Repudiation / Denial of Service | MEDIUM | returned environment/memory failures | mitigate | Recording-handler tests require zero events for returned errors. |
| T-02-11 | Denial of Service | HIGH | atomic reconfiguration and memory finalizer handler | mitigate | Use atomic diagnostic state and the finalizer-safe wrapper without entering lifecycle locks. |
| T-02-SC | Tampering | LOW | package-manager inputs | mitigate | Add no dependency and leave module files unchanged. |

- Targeted environment and memory race suites
- Exact status-release and error-chain assertions
- Zero-emission tests for returned errors
- Source inspection of lock order and allowed diagnostic attrs

T-02-06 is accepted at MEDIUM severity only at the explicit trusted consumer-callback boundary. No HIGH threat is accepted or unresolved.
