<objective>
Give the inference example a fail-fast, actionable diagnostic when ONNX Runtime bootstrap fails specifically because the host GOOS/GOARCH combination is unsupported by automatic bootstrap (issue #42 / DX-01). Purpose: Close DX-01 exactly as scoped by CONTEXT.md D-01/D-02 — example-UX only, using the codebase's existing sentinel-error + errors.Is idiom (not string-matching), without touching any other ort/ runtime behavior.
